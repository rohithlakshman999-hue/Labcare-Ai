# LabCare AI — Security, Privacy & Safety Controls

## 1. Safety Controls (Non-Destructive Operations)
- **Recommendation-Only Guidance**: LabCare AI provides actionable, structured Standard Operating Procedures. It does **NOT** automatically execute arbitrary shell commands, terminate processes, wipe disks, or modify network interfaces without explicit technician authorization.
- **Guided Checklist Verification**: Hypotheses generated by Machine Learning models remain strictly classified as *suspected* until an authorized technician inspects the workstation and marks physical verification complete.
- **Two-Step Recovery Verification**: Incidents cannot transition to `Resolved` until post-repair measurements are collected and confirmed by a human operator.

## 2. Agent Authentication & Enrollment
- **Outbound-Only Communication**: Monitoring agents initiate outbound HTTPS requests to the backend server. No listening ports or open ingress sockets are required on lab computers.
- **Token Hashing**: Agent enrollment tokens (`lca_agent_...`) are cryptographically generated with 24 bytes of entropy and hashed in the database using SHA-256 (`hashlib.sha256`). Plaintext tokens are never stored in the database.
- **Tenant & Device Isolation**: Ingested metrics and heartbeats are verified against the specific device token hash, preventing unauthorized devices from spoofing metrics.

## 3. Privacy & Data Minimization
- **No Keylogging or Content Inspection**: Telemetry is strictly limited to hardware performance counters (CPU, RAM, Disk, Network socket ping) and sanitized application event logs.
- **Untrusted Log Handling**: System logs are treated strictly as untrusted text strings. The chatbot and diagnostic parser sanitize log contents to prevent prompt injection or rule override attempts.
- **Conversation History Controls**: Technicians can review or delete troubleshooting chat session histories at any time.
